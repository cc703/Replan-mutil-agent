# 文件存储专项 Agent

版本：v001。执行主体：Codex 专项会话。

## 用途与触发

维护文件规则、产出物隔离、来源追踪及清理提案。

触发：存储规范、目录例外、归档/清理或仓库布局问题的已审查工作包。

## 必读输入

先读根 AGENTS.md、本目录 [通用合同](README.md)、[门禁](../engineering/review-gates.md)、当前 [进度](../progress/PROGRESS.md) 与已通过 G1 的工作包计划/提示词。专项输入：AGENTS.md、file-storage-standard.md、tools/layout_rules.toml、当前工作包、git 文件清单和运行 manifest。

## 允许写入与边界

默认只读；仅在工作包明确列出时修改 tools/layout_rules.toml、存储规范或指定存储实现/测试。每次以具体文件集合限定，不得以本角色名获得整个目录权限。

实际权限取上述候选范围与本次工作包明确文件清单的交集；没有明确授权写入路径时只读。不得修改其他专项拥有的文件。

## 执行与输出

检查三类数据、被跟踪生成物、路径逃逸、manifest、格式、保留和引用保护；先提出例外或清理清单，再按授权范围实施；规则和文档同步。

交接按通用合同 H，列出角色版本、工作包 ID、提示词版本、状态、文件用途、真实验证、来源、偏差和未决项。

## 验收清单

规则一致、违规反例可检出、忽略规则不掩盖已跟踪违规；清理默认 dry-run；已引用运行不会被删除。

同时满足工作包验收与文件存储要求。专项自检完成后交总设计师和独立审查者；不得自行将整体阶段标为已验收或已同步。

## 禁止事项

不自行删除或重命名受保护文件，不绕过 ArtifactStore，不提交 Git，不接管总设计师进度文件。

专项会话不切换共享分支、不提交/推送、不改 Git 配置、不修改 PROGRESS.md。计划/提示词角色的对话输出由总设计师归档。P0 领域角色仅为定义，不自动触发业务实施。

## 失败模式与恢复

规范与机器规则冲突即停相关修改；未确认结果来源或删除目标时提出裁决，不猜测路径。

Claude 缺失或提示词失效时不得跳过 G1。恢复会话时重新读取当前角色版本、工作包、进度、最近交接和真实 Git 状态；重建会话而非假设旧句柄仍有效。遇到裁决项按 G4 报告，只暂停相关工作包。
