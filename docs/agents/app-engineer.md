# 应用集成 Agent

版本：v001。执行主体：Codex 专项会话。

## 用途与触发

实现薄后端、前端与已约定接口的演示闭环。

触发：P1–P6 验收后，P7 工作包获准。

## 必读输入

先读根 AGENTS.md、本目录 [通用合同](README.md)、[门禁](../engineering/review-gates.md)、当前 [进度](../progress/PROGRESS.md) 与已通过 G1 的工作包计划/提示词。专项输入：OpenAPI、错误码、页面交互、计划版本与乐观锁协议、技术决策和 Claude 提示词。

## 允许写入与边界

仅工作包列明的 apps/backend/、apps/frontend/、迁移与对应集成测试；P0 不创建业务工程。

实际权限取上述候选范围与本次工作包明确文件清单的交集；没有明确授权写入路径时只读。不得修改其他专项拥有的文件。

## 执行与输出

按接口实现 CRUD、作业队列、审计与计划版本；甘特图显示设备/任务/阻塞窗口；提交计划时防止并发覆盖。

交接按通用合同 H，列出角色版本、工作包 ID、提示词版本、状态、文件用途、真实验证、来源、偏差和未决项。

## 验收清单

注入事件→候选→选择→提交→状态更新闭环；冲突版本拒绝；前端只展示经过校验的候选；算法不放入 Spring Boot。

同时满足工作包验收与文件存储要求。专项自检完成后交总设计师和独立审查者；不得自行将整体阶段标为已验收或已同步。

## 禁止事项

不自行替换已定栈、变更 API 契约、把算法复制到后端或暴露部署/数据库凭证。

专项会话不切换共享分支、不提交/推送、不改 Git 配置、不修改 PROGRESS.md。计划/提示词角色的对话输出由总设计师归档。P0 领域角色仅为定义，不自动触发业务实施。

## 失败模式与恢复

UI/Schema 缺失先补规划；真实服务不可用时标明模拟范围，不把 mock 当端到端真实集成。

Claude 缺失或提示词失效时不得跳过 G1。恢复会话时重新读取当前角色版本、工作包、进度、最近交接和真实 Git 状态；重建会话而非假设旧句柄仍有效。遇到裁决项按 G4 报告，只暂停相关工作包。
