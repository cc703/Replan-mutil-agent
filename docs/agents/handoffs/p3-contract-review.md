## 阻断

`src/simulator/engine.py` 的 `Simulator.run` 允许监听器嵌套运行超过外层截止，外层返回时无条件将 clock 写回其 t_end，而内层已提交的未来事件仍在状态和历史中。独立实际复现：单设备 d，a [0,2)、b [4,5)，首次事件监听器调用 `engine.run(6)`，外层调用 `engine.run(3)`。返回时 clock=3，但 a、b 均为 DONE；`replay(result.log)` 抛 `ReplayMismatch`，在日志索引 11 期待 time=4 的 DurationSampled，实际是 time=3 的 EndRun。违反 run 截止槽和精确回放，也会造成时间倒退与未来状态泄漏。需维持合法重入并明确嵌套截止的正确处理，增加独立成功重入以及回滚对照，修复后重审。
