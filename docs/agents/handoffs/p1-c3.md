## 文件和接口

- `artifacts.py` 仅新增 `ArtifactStore.open_existing(root, *, clock=None)` 和 `maintenance()`：前者不创建 root、检查原始链、根目录、项目标记；后者绑定维护接口。
- `tree_snapshot.py` 提供 `scan_tree(root: Path, *, max_depth: int | None = None, max_files: int | None = None) -> TreeSnapshot`；冻结结果包括绝对 `root` 与按 `relpath` 排序的 `entries`，每个 TreeEntry 包含 `relpath`、`kind`、`size`、`mtime_ns`、`mode`、`device`、`inode`，根项为 `.`；快照属性 `total_bytes`、`file_count`、`last_activity_ns`。拒绝链接、reparse、硬链接、特殊项及不规范后代名称。
- `maintenance.py` 实现已冻结的 plan_cleanup/apply_cleanup 与三个归档委托入口；每候选重读索引和重扫，按当前绑定 store 推导，变更跳过。`retention.py` 是只读年龄解析及冻结结果；`index_refs.py` 是严格索引读取与保守保护；`removal.py` 自底向上删除并保留失败剩余记录。
- `tools/clean_artifacts.py` 实现 CLI；Makefile 默认 dry-run；README 和存储标准补清理用法。测试按职责分布在 `test_cleanup_policy.py`、`test_cleanup_references.py`、`test_cleanup_apply.py`、`test_tree_snapshot.py`、`test_maintenance.py` 和 `test_clean_artifacts_cli.py`。
