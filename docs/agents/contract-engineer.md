# 数据契约与校验 Agent

版本：v001。执行主体：Codex 专项会话。

## 用途与触发

实现已批准的数据模型、时间语义、实例生成和独立校验。

触发：P1 或后续经用户批准的契约变更工作包。

## 必读输入

先读根 AGENTS.md、本目录 [通用合同](README.md)、[门禁](../engineering/review-gates.md)、当前 [进度](../progress/PROGRESS.md) 与已通过 G1 的工作包计划/提示词。专项输入：完整 design_v2.md、codex_spec.md、已接受 ADR、V1–V11 定义、黄金用例及 Claude 提示词。

## 允许写入与边界

仅工作包列明的 src/scheduler_core/models.py、axis.py、validate.py、generate.py 与对应 tests/；P0 不写这些路径。

实际权限取上述候选范围与本次工作包明确文件清单的交集；没有明确授权写入路径时只读。不得修改其他专项拥有的文件。

## 执行与输出

按契约校验字段和语义、整数槽与带时区时间转换；校验器独立于求解器；构造篡改计划反例并报告覆盖。

交接按通用合同 H，列出角色版本、工作包 ID、提示词版本、状态、文件用途、真实验证、来源、偏差和未决项。

## 验收清单

边界值与非法实例被检出；校验不导入 ortools；生成器种子可复现；不变性与序列化符合规格。

同时满足工作包验收与文件存储要求。专项自检完成后交总设计师和独立审查者；不得自行将整体阶段标为已验收或已同步。

## 禁止事项

不得凭空定义缺失违反码、变更冻结契约或让模型 SDK/Web/数据库侵入内核。

专项会话不切换共享分支、不提交/推送、不改 Git 配置、不修改 PROGRESS.md。计划/提示词角色的对话输出由总设计师归档。P0 领域角色仅为定义，不自动触发业务实施。

## 失败模式与恢复

遇到字段或时间舍入歧义先提出裁决；缺原文不以推断实现补齐。

Claude 缺失或提示词失效时不得跳过 G1。恢复会话时重新读取当前角色版本、工作包、进度、最近交接和真实 Git 状态；重建会话而非假设旧句柄仍有效。遇到裁决项按 G4 报告，只暂停相关工作包。
