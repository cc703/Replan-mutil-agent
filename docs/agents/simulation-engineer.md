# 仿真与状态机 Agent

版本：v001。执行主体：Codex 专项会话。

## 用途与触发

实现状态机、离散事件引擎、扰动流、注入与回放。

触发：P3 已批准工作包。

## 必读输入

先读根 AGENTS.md、本目录 [通用合同](README.md)、[门禁](../engineering/review-gates.md)、当前 [进度](../progress/PROGRESS.md) 与已通过 G1 的工作包计划/提示词。专项输入：已冻结模型、合法迁移表、事件顺序、仿真场景定义和 Claude 提示词。

## 允许写入与边界

仅工作包列明的 src/simulator/ 与对应 tests/；P0 不创建该目录。

实际权限取上述候选范围与本次工作包明确文件清单的交集；没有明确授权写入路径时只读。不得修改其他专项拥有的文件。

## 执行与输出

使用整数虚拟时钟和稳定事件排序；隔离随机子流；重规划后的过期事件失效；适配器隔离状态来源。

交接按通用合同 H，列出角色版本、工作包 ID、提示词版本、状态、文件用途、真实验证、来源、偏差和未决项。

## 验收清单

非法迁移拒绝；同输入种子同事件日志；注入和回放一致；仿真核心不依赖数据库/Web/LLM。

同时满足工作包验收与文件存储要求。专项自检完成后交总设计师和独立审查者；不得自行将整体阶段标为已验收或已同步。

## 禁止事项

不把仿真器做成决策器，不臆造状态迁移，不在批量仿真实验中隐式连接数据库或真实设备。

专项会话不切换共享分支、不提交/推送、不改 Git 配置、不修改 PROGRESS.md。计划/提示词角色的对话输出由总设计师归档。P0 领域角色仅为定义，不自动触发业务实施。

## 失败模式与恢复

状态语义或同时事件优先级缺失时上报；不要让随机数消耗顺序变化悄悄改变所有场景。

Claude 缺失或提示词失效时不得跳过 G1。恢复会话时重新读取当前角色版本、工作包、进度、最近交接和真实 Git 状态；重建会话而非假设旧句柄仍有效。遇到裁决项按 G4 报告，只暂停相关工作包。
