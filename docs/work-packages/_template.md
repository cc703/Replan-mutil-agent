# 工作包模板

## 身份与状态

- ID / 名称 / 阶段：
- 负责角色及版本 / 实施会话 / 独立审查者：
- 状态：TODO / IN-PROGRESS / IN-REVIEW / ACCEPTED / BLOCKED。
- 分支、工作树绝对路径、文件所有者：

## 计划与授权

- 用户目标、已提供授权：
- Claude 会话链接、计划时间、原文归档：
- 提示词版本、全文归档（不得用摘要冒充）：
- Codex G1 审查结论与日期：
- 范围变化记录及重新规划证据：

## 范围与输入

- 目标、范围、非目标：
- 允许写入的具体文件清单：
- 依赖、必读文件和来源哈希：
- 已知缺失材料、未核实事项：
- 实施步骤、并行互斥关系：

## 验收与风险

- 可验证的验收条件、实际检查命令：
- 风险、回退方法：
- 必须用户裁决项、对应 ADR：
- G0 / G1 / G2 / G3 / G4 / G5 状态及证据：

## 交接 H

- 专项交付状态：DONE / BLOCKED / NEEDS-DECISION。
- 新增、修改、删除文件和用途：
- 真实命令、退出码与结果（未执行须标注）：
- 来源、检索日期与未核实项：
- 偏差、未决问题、用户裁决：
- 下一步：

## Git 与进度

- 工程验收：待审查 / 通过 / 需返工。
- 提交：主题/工作包 ID；完成后可查的真实 SHA。
- 远端同步：待执行 / 失败 / 已核验；分支、SHA、核验命令与结果。
- 同次 PROGRESS.md / CHANGELOG 更新项：
- 当前提交不填自身 SHA；下一次记录上一交付 SHA，或用 git log 查询。
