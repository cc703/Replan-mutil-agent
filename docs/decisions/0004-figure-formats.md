# ADR 0004：按真实格式导出与入库图表

- 状态：ACCEPTED（P0 总设计师工程审查）
- 日期：2026-11-09（Asia/Shanghai）
- 来源：开发规格 v1.1 第 2.6 节；Claude P0 计划。
- 工作包：P0-A、P0-C

## 背景

原规格示例从 PNG 草稿“复制”到 SVG 名称。复制与重命名不能得到真正的矢量格式，可能让论文结果与文件格式不符。

## 决定

绘图工具原生导出 PNG 预览及 SVG/PDF 最终结果；报告工具只复制实际存在、格式一致的文件，不通过改后缀转换。
只有 PNG 时保留 .png 并说明限制，由用户审核最终使用；不得伪称矢量图。PNG/PDF 签名与 SVG XML 根元素检查纳入治理验证。

## 影响与验证

这不改变业务数据契约或算法；图表生成/报告工具在后续阶段实现。P0 仅实现格式检查，不能宣称已经实现图表导出或报告复制。
最终结果登记 run_id、commit、命令和真实格式，拒绝 dirty 或未完成运行。
