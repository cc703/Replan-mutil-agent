# ADR 0005：文档语言与提交约定

- 状态：ACCEPTED（总设计师默认工程约定，用户可随时调整）
- 日期：2026-11-09（Asia/Shanghai）
- 来源：用户授权建立约束和 GitHub 同步流程；Claude P0 建议。
- 工作包：P0-A、P0-B

## 决定与理由

文档正文用中文，代码标识符、路径和命令用英文。提交采用 `type(scope): subject` 形式的英文 Conventional Commits，scope 标识工作包，便于后续检索和自动整理。
每个可验收工作包由总设计师更新进度、提交并同步 GitHub；专项 Agent 无提交、推送或改 Git 配置权限。

## 边界

默认格式不制造新的批准步骤，不阻挡用户已授权的常规工作。重大设计变化仍由用户裁决；本约定不决定项目开源许可证或仓库可见性。
进度明确区分本地提交与远端同步：只在核对远端后记录成功；失败保留待同步，不强推、不改写公共历史。
