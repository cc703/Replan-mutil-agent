# ADR 0006：人员资源契约提案

状态：PROPOSED；用户 G4 PENDING。依据 `docs/source/design_v2.original.md:211`、`:214`、`:217`、`:226`、`:451`、`:758`，以及 `docs/source/codex_spec_v1.1.original.md:325`、`:334`、`:376`。规格缺人员字段但 V7 已存在。

推荐 Person、阻塞式人员日历、任务技能集合和显式人员需求、分配 person_id、实例 persons；完整字段、边界、反例与兼容规则见 [P1 契约提案](../planning/p1-contract-proposal.md)。替代为单技能和开放窗口；它们分别限制多技能或改变空日历含义。推荐空日历无阻塞，技能非空或显式要求时必须分配，已分配人员始终校验。缺分配和未知引用不能通过；V7 使用 detail，新增 subcode 须另经 G4。旧数据缺省为不启用人员需求。

影响：输入、独立校验、未来求解与生成器均受影响；缺席事件仅列影响。人员是否占准备、DONE 历史占用与冻结 person 仍待裁决。不裁决则不能实施相关契约；本提案不改变原文，不授权 P1-A。

G3 R1 细化：人员准备占用推荐仅执行区间，替代含准备；DONE 推荐仅当前视野内历史参与资源校验，替代完整历史；冻结人员推荐保持并由 V11 检查，V8 保留设备与开始，替代允许替换或修改 V8。各选择的影响和未裁决后果见主提案，均为 PROPOSED。
