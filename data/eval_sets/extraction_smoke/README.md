# Extraction pipeline smoke v001

These seven anonymous synthetic cases cover clear requests, relative time,
entity ambiguity, missing fields, soft preferences, multiple constraints, and a
deadline conflicting with the existing miniature plan. The utterances and their
independently recorded responses exercise the
offline parser and scorer only. Gold labels are read only by the scorer and are
not supplied to extraction. They are not the D7 research test set and do not
measure DeepSeek accuracy. Real evaluation remains subject to D7's human review,
annotation, split, adversarial and leakage controls.
